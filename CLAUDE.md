# FIT_APP · contexto mínimo para Claude Code

1. Lee `AGENTS.md` para las reglas del repositorio. No cargues todos los documentos ni todo `lib/` al iniciar.
2. Ubica la tarea con `docs/CODEBASE_MAP.md` o `tools/context.ps1 -Area <área> -Query <símbolo>`. Lee solamente los archivos y rangos relacionados, más sus pruebas.
3. Si necesitas relaciones visuales, abre `docs/ai/FIT_APP.canvas` en Obsidian. Para contexto de texto usa el mapa Markdown: no pegues el JSON del Canvas en la conversación.
4. Resume errores de herramientas y pruebas; expande la salida solo cuando un fallo concreto lo exija. Preserva los cambios locales existentes.
